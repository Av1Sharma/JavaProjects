# Java Projects

A collection of Java projects built outside AP Computer Science, including small simulations, games, and object-oriented programming exercises.

## Browse the projects

There is no single hosted demo because these are separate Java programs. Browse the [project folders](https://github.com/Av1Sharma/JavaProjects) to see Aquarium Project, Cryptography, DessertShoppe, Guitar Hero, Little Crab, Netflix, and other experiments.

## What it uses

- **Java** for the programs and object-oriented design.
- **The Java standard library** for core language features and user interaction.

## Run it yourself

Install a Java Development Kit (JDK), clone the repository, and open the individual project folder in an IDE such as IntelliJ IDEA or Eclipse. Select the project’s main class and press **Run**. These folders are separate exercises, so the right entry point and any extra setup can vary by project.

```bash
git clone https://github.com/Av1Sharma/JavaProjects.git
cd JavaProjects
```

If you prefer the command line, open a folder and compile its Java source files with `javac`, then run the class that contains `main`. Check the folder’s source files for the correct class name.
